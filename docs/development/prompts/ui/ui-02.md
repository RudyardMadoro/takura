# UI-02 — Premium Header, Navigation & Footer

Using the UI-01 design system, modernize the global public website layout inspired by Theratio.

**Scope:**
1. Redesign the desktop header with an elegant brand presentation.
2. Implement a responsive navigation bar and mobile menu.
3. Add refined hover, active, focus, and sticky-header states where appropriate.
4. Redesign the footer with business divisions, useful links, contact information, and enquiry CTAs.
5. Ensure consistent spacing and layout across existing public pages.
6. Preserve existing routes and navigation functionality.
7. Use actual configured business details rather than invented contact information.

**Acceptance criteria:**
- All existing public navigation links work.
- Mobile navigation functions correctly.
- Keyboard navigation and focus behavior work.
- No horizontal overflow at small widths.
- Header and footer render correctly with SSR.
- Relevant tests pass.

**Rules:** Reuse existing components where possible, keep changes local, preserve functionality, and do not auto-commit or push.

**Deliverables:** Implementation changes, `UI-02-REPORT.md`, screenshots where possible, test results, and suggested commit message.

Suggested commit: `feat(public): redesign responsive navigation and footer`
