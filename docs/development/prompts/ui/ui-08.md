# UI-08 — Customer Enquiry & Quotation UX

Modernize existing public enquiry and quotation-request forms to match the new Takura Properties architectural design.

**Scope:**
1. Audit existing enquiry entry points and form workflows.
2. Redesign input fields, labels, validation states, and submission feedback.
3. Improve mobile form usability and keyboard navigation.
4. Provide clear service/project context when entering an enquiry.
5. Improve supporting attachment controls without weakening upload security.
6. Improve successful submission and recoverable error states.
7. Preserve existing backend validation, persistence, and enquiry ownership rules.
8. Reuse current APIs; extend only if required.

Do not implement automated quote/PDF generation or payments.

**Acceptance criteria:**
- Existing enquiry types can be submitted successfully.
- Required validation works.
- Attachments retain correct security and scanning behavior.
- Success/error feedback is accessible and clear.
- No regression in existing browser/API tests.

**Rules:** Local development only; preserve existing functionality; no automatic commits or pushes.

**Deliverables:** Implementation changes, `UI-08-REPORT.md`, tests and screenshots, suggested commit message.

Suggested commit: `feat(public): modernize customer enquiry and quotation forms`
