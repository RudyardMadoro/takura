# UI-07 — Board Supply & Cut-to-Size UX Modernization

Improve the public-facing experience for Takura Properties' board supply and cutting business.

**Scope:**
1. Redesign existing board catalogue/listing pages.
2. Improve board specification presentation using existing data.
3. Create attractive, responsive product cards and detail views.
4. Improve usability of full-sheet and cut-to-size request journeys.
5. Preserve separate attachment-supported and assistance-request workflows.
6. Improve file-selection feedback, field descriptions, and validation presentation.
7. Reuse existing backend APIs and secure upload infrastructure.

Preserve upload ownership, malware scanning, clean-file association, and private access controls.

Do not introduce inventory, payments, checkout, or automated fabrication.

**Acceptance criteria:**
- Existing board and cutting journeys still work.
- Secure upload and enquiry association remain intact.
- Mobile forms are usable.
- API contracts remain compatible.
- Relevant integration and browser tests pass.

**Rules:** Local only, preserve security and functionality, do not auto-commit or push.

**Deliverables:** Implementation changes, `UI-07-REPORT.md`, test evidence, suggested commit message.

Suggested commit: `feat(public): improve board supply and cutting enquiry UX`
