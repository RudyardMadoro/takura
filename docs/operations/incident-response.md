# Incident response quick guide

Operator routing contacts are deliberately pending. Classify customer submission/data loss, identity,
file-scan, communication and availability incidents. Preserve audit evidence without copying payloads,
tokens or private files into chat/tickets. Revoke credentials and quote grants through supported commands,
pause affected workers, retain the immutable release manifest and communicate only verified facts.

For suspected disclosure, involve the designated privacy owner and legal adviser; do not promise a breach
classification or notification timeline before jurisdictional review. Post-incident work records safe
timestamps, route templates, release digest, provider references and corrective actions.
